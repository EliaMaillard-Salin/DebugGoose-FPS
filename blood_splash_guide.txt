BLOOD SPLASH ON ENEMY HIT (ONE EFFECT PER GUN) - UNREAL ENGINE

Idea: spawn a Niagara blood effect at the point where the shot lands, and keep one effect variable per gun so each gun can have its own.
This is the same pattern as the muzzle flash. From the earlier photo of BP_AR, the assumption is that a Line Trace By Channel feeds a Break Hit Result node, so the splash goes right after that trace.


STEP 1: GET TWO EFFECTS
- On Fab (the Fab button in the Content Drawer), search "blood niagara", filter to free, and add the pack to your project.
- Pick two different effects: a smaller, faster burst for the AR and a bigger one for the rifle. You can also duplicate one effect and change its size or colour.


STEP 2: ADD A VARIABLE TO EACH GUN
1. Open BP_AR. In My Blueprint, click + next to Variables and name it BloodEffect.
2. Set its type to Niagara System (Object Reference), tick Instance Editable, and compile.
3. At the bottom of Details, set the Default Value to the AR's effect.
4. Open the second gun's Blueprint and do the same with its own effect. If it is a child of BP_AR, skip creating the variable and open Class Defaults to pick a different effect.


STEP 3: SPAWN IT WHEN A SHOT HITS AN ENEMY
1. In the fire logic, find the Line Trace By Channel node and its Return Value (red pin, true if it hit something). Add a Branch on it.
2. From True, add a check that the hit is an enemy:
   - Drag from the trace's Out Hit and add Break Hit Result.
   - Drag from Hit Actor and add Actor Has Tag, with the tag "Enemy".
   - Connect it to a second Branch.
3. On the enemy Blueprint, add "Enemy" under Class Defaults > Actor > Tags. A tag avoids needing the enemy's class name.
4. From the second Branch's True, add Spawn System at Location (the Niagara one).
5. Connect BloodEffect to System Template, and Break Hit Result > Location to Location.
6. For the direction, drag Break Hit Result > Impact Normal into a Make Rot from X node and connect it to Rotation. The splash then sprays out of the surface that was hit.
7. Leave Auto Destroy ticked, and compile.

Do the same in the second gun's fire logic, unless it inherits from BP_AR. In that case it reuses the logic, and only the default effect differs.


STEP 4: TEST
- Shoot an enemy with each gun and check that each gives a different splash.
- Shoot a wall, and nothing should appear.


IF YOUR BULLET HANDLES THE HIT INSTEAD
The SpawnActor BP Bullet node suggests the bullet may deal damage itself. If so, put this in the bullet's hit event:
Event Hit (or On Component Begin Overlap) > the same Spawn System at Location, with the effect passed in from the gun.
